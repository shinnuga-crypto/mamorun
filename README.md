# まもるん（Guardian Mascot） v0.9

ソースコードと配布版: https://github.com/shinnuga-crypto/mamorun （ライセンスは GPL-3.0）

感染を防ぎ、悪意あるソフトウェアに情報を勝手に外へ出させないためのマスコットです。
画面の中に立ってプログラムの起動と通信を見張り、危険そうなものを止めて、止めるかどうかの判断材料を詳しく示します。
判断はすべてPC内で行い、**通信内容や記録を外部へ送りません**（このアプリ自身は通信しません）。

> **ウイルス対策ソフトの代わりではありません。** Windows Defender などと併用する「最後の番人」です。

## 役割分担

既知のマルウェアの検出、スクリプトの検査、ランサムウェア対策は Microsoft Defender の役割です。まもるんは重ねて作りません。
まもるんの役割は、**情報を読ませないこと、外へ出させないこと、止める判断の材料を出すこと**です。
Defender が実際に働いているかは、「見守り状況」の「Windowsの防御」タブで確認できます（読み取りのみ）。
他社のウイルス対策と併用していると、Defender は受動モードになり、ASR などが働かないことがあります。

## 使い方

1. ZIPを展開し、`GuardianMascot.exe` をダブルクリックします。ほかのインストールは要りません。
   確認の画面で「はい」を押すと、管理者権限で起動し、送信前の遮断も有効になります。「いいえ」を押すと、遮断と切断なしで起動します。
   署名のないプログラムなので、初回に「WindowsによってPCが保護されました」と出ることがあります。入手元に心当たりがあるときだけ、「詳細情報」→「実行」で進めてください。
2. 最初は **観察モード** で数日試すのがおすすめです（検知しても止めません）。
   ```
   GuardianMascot.exe --observe
   ```
3. マスコットの操作
   - クリック: 状況を聞く / 確認待ちを開く
   - ドラッグ: 移動（位置は記憶します）
   - 右クリック: 見守り状況、15分休ませる、キャラクター（聖女ルーチェ / 神父アンセル / 表示しない）、大きさ、定位置に戻す、画像の読み直し、Windowsの起動時に起動する、警告画面のお試し、終了

### キャラクターを表示しない

右クリック →「キャラクター」→「表示しない」で、画面から消えます。見張りは続きます。
操作はタスクトレイの盾のアイコンから行い、知らせはWindowsの通知と確認画面で出ます。キャラクターを選び直すと、また表示されます。

### Windowsの起動時に起動する

右クリック →「Windowsの起動時に起動する」で切り替えます。管理者権限で起動しているときだけ変更できます。
タスクスケジューラに `GuardianMascot` として登録するので、起動のたびの確認は出ません。プログラムの場所を移したら、一度外して設定し直してください。

## 危険度ごとの動き

| 危険度 | 点数 | まもるんの動き |
|---|---|---|
| 低 | 0〜39 | 何もしない（一覧には表示） |
| 中 | 40〜69 | 止めずに確認する |
| 高 | 70〜100 | **自動で一時停止**してから確認する（管理者権限があればIPv4接続も切断） |

点数を上げる要素の例: 署名なし、ダウンロードや一時フォルダからの実行、システムと同名の偽装、
PowerShellなどの外部通信、難読化された命令、文書アプリからの起動、遠隔操作でよく使われるポート、
定期的な接続の繰り返し、多数の宛先への接続、外部からの接続。

点数を下げる要素: 有効なデジタル署名、Windowsのシステムフォルダ、Program Files。

止めたプログラムは次のどれかを選べます。再開系のボタンは誤操作防止のため3秒待たないと押せません。

- **止めたままにする**（あとでマスコットをクリックすると開きます）
- **終了させる**
- **今回だけ再開**（そのプログラムが終了するまで許可）
- **常に信頼**（パスとファイル内容が同じ間だけ。更新されると再び判定します。PowerShell や cmd など攻撃にも使われる標準ツールは選べません）

Windowsの動作に必要なプログラム（システムフォルダの svchost.exe など）は、不安定になるため止めずに知らせるだけです。
まもるんを終了すると、止めていたプログラムはすべて再開します。
異常終了した場合は、次回起動時に「止めたままのプログラム」として確認します。

## プログラムの詳しい調査

外部へつないでいるプログラムを見つけると、裏で自動的に調べます。右クリックの「見守り状況」→「外部へつなぐプログラム」に、危険な点の多い順に並びます。
行をダブルクリックするか、警告画面の「詳しく調べる」で詳細を開き、一時停止、再開、終了を選べます。
危険な点が見つかった場合は、詳細画面が自動で開きます。

| 調べるもの | 内容 |
|---|---|
| デジタル署名 | 状態（有効、署名なし、改ざんの疑い、失効、期限切れ、信頼されていない発行元）、埋め込みかカタログか、ハッシュ方式、タイムスタンプ、証明書チェーン（署名者、組織、発行者、有効期間、シリアル、拇印） |
| ファイル | 場所、大きさ、日時、SHA-256 |
| バージョン情報 | 会社名、製品名、本来のファイル名。署名者と違う有名企業を名乗っていれば「なりすまし」として示す |
| 入手元 | Mark of the Web のゾーンとダウンロード元のURL |
| 実行ファイルの構造 | セクションとエントロピー、圧縮ツールの痕跡、書き込みと実行が両方できる部分、末尾の追加データ、署名領域の余分なデータ（CVE-2013-3900）、注入や資格情報の復号に使える機能の読み込み |
| プロセス | 起動元のつながり、コマンドライン、ユーザー、権限、接続先 |
| 読み込み中のDLL | システムフォルダ外のDLLの署名。署名済みアプリが署名のないDLLを読んでいれば、サイドローディングの疑いとして示す |

**有効な署名は安全の証明ではありません。** 盗まれた証明書による署名は見分けられず、失効の確認も通信しないため行っていません（Windowsのキャッシュのみ）。
調査対象は読むだけで、実行しません。他のユーザーや管理者権限のプロセスは、管理者権限がないと一部を読めません。

## 起動の見張り（感染の入口）

通信を待たずに、新しく起動したプログラムを0.5秒ごとに確かめます。

| 危険度 | 例 | まもるんの動き |
|---|---|---|
| 高 | エクスプローラーやブラウザから起動した、難読化やダウンロード命令付きの PowerShell（ClickFix の手口）、URL付きの mshta や certutil、ダウンロードフォルダのスクリプト、文書アプリが起動したシェル、システムと同名の偽装 | 一時停止して確認する |
| 中 | ダウンロードや一時フォルダの署名なしプログラム、リモートデバッグ付きのブラウザ、難読化された PowerShell | 止めずに確認する |

制限: 確認の間隔があるので、起動を未然に防ぐものではなく、起動直後に止めるものです。0.5秒以内に終わるプログラムは見逃します。一時停止の前に動いた分は取り消せません。

## 厳格モード（既定でオン）

右クリックの「厳格モード」で切り替えます。署名がなく、Windows のシステムフォルダのものでもないプログラムを、低い点数でも確認なしには通しません。

- **送信前の遮断が有効なとき:** 通信を止めたまま確認します。「今回だけ再開」か「常に信頼」で通します。一度通信しただけのアプリも、次回から自動では通しません。
- **遮断が無効なとき:** 止められないので、初めて外へつないだ時点で知らせます。

**有効な署名があるものは通します。** 正規の署名つきアプリが乗っ取られた場合は素通りするので、下の罠と Sysmon 連携で補います。

## 罠

右クリックの「罠を仕掛ける」で、情報を探し回るマルウェアが読みそうな名前の偽物を置きます（`Documents\wallet_seed_backup.txt` など）。どのアプリも開かない名前にしてあるので、本物のアプリを壊しません。

| 読んだプログラム | まもるんの動き |
|---|---|
| 署名なし、または PowerShell などの標準ツール | 一時停止して確認する |
| 署名つき（正規のソフトの場合があるので止めない） | 送信前の遮断が有効なら、**外への新しい接続だけを封じて**確認する。無効なら知らせるだけ |
| ウイルス対策、検索のインデックス、OneDrive（正規の場所か署名があるもの）、信頼済み | 何もしない |

- 同じ名前のファイルがあれば置きません。
- 管理者権限が必要です。Windows の「ファイルシステムの監査」を有効にします（Windows全体の設定です）。「罠を外す」でファイルを消し、設定を元に戻します。
- バックアップソフトなど全ファイルを読むものは確認が出ます。「常に信頼」すると以後は出ません。
- 読まれた後に動くので、止めるのは読み取りではなく送信です。決まったパスだけを読むマルウェアは罠に触りません（次の見張りで補います）。

## 認証ファイルの見張り

右クリックの「認証ファイルを見張る」で、本物のファイルの読み取りを見張ります。ブラウザ（Chrome、Edge、Brave、Firefox）のパスワードと Cookie、SSH鍵、AWSの認証ファイルが対象です。
本来読むプログラム（ブラウザ自身、ssh.exe など。名前に加えて署名か正規の場所を確かめます）は対象外です。

- **最初は記録だけで、何も止めません。** 「検知の記録」に出るものを確かめて問題がなければ、「認証ファイルが読まれたら止める」をオンにします。止めるときの動きは罠と同じです。
- 本物のファイルに監査の設定を追加しますが、中身は変更しません。ほかのツールの監査設定があるファイルには触りません。やめると設定を外します。
- ブラウザがファイルを置き換えると設定が消えるので、約5分ごとに付け直します。その間の読み取りは見逃すことがあります。
- パスワードのインポート、バックアップソフトなどは対象になります。

## Sysmon 連携（任意、おすすめ）

Microsoft の Sysmon を入れると、0.5秒ごとの確認で見逃していたものが分かるようになります。

1. `Sysmon` フォルダの `Sysmon導入.cmd` をダブルクリックし、確認の画面で「はい」を押します。
2. 利用条件を確認して `Y` を入力します（[Sysinternals のライセンス](https://learn.microsoft.com/en-us/sysinternals/license-terms)）。
3. Windows の組み込み機能を使ったときは、Windows を再起動します。再起動するまで記録を読めません。
4. まもるんを管理者権限で起動し直します。見守り状況の上部が「Sysmon: 連携中」になれば動いています。

導入ファイルは、導入済みなら設定だけ更新し、Windows 11 の組み込み機能があればそれを有効にし、なければ Microsoft の公式サイトからダウンロードします。ダウンロードしたものは Microsoft の署名を確かめてから実行します。やめるときは `Sysmon削除.cmd` を使います。
再配布が禁じられているので、Sysmon 自体は同梱していません。まもるん本体は通信しません。通信するのはダウンロードするときの導入ファイルだけです。

| 記録するもの | まもるんの動き |
|---|---|
| プログラムの起動 | 起動の見張りと同じ基準で判定。すぐ終了したプログラムも、本来のコマンドラインで「終了後に検知」として知らせる |
| 名前の問い合わせ（DNS） | Telegram、Discord、Steam、Cloudflare Workers、Pastebin、LLM API（Hugging Face、Gemini など）の名前を、ブラウザと署名済みアプリ以外が引いたら判定する。公開された事件の通信先は、署名があっても止める。詳細画面に問い合わせ先も出す |
| 自動起動の登録（Runキー、利用者のCOM登録） | 署名なしのプログラムや、PowerShell などでコマンドを動かす登録、ブラウザのデータフォルダのDLLを読ませる登録を判定する。すべての登録を記録に残す |
| 記録の消去 | 番号の巻き戻りを見つけて警告する（痕跡を消す手口） |

制限:

- Sysmon は記録するだけです。プログラムを止めるのは今までどおり検知の後で、起動を未然に防ぐものではありません。
- 記録を読むには管理者権限が必要な場合があります。読めないときは「Sysmon: 読めません」と表示します。
- 管理者権限を持つマルウェアは、Sysmon 自体を止められます。サービスやドライバーの停止は5秒以内に検知して知らせますが、止まるのを防ぐことはできません。自分で `Sysmon削除.cmd` を実行したときも1回知らせます。
- 登録を見つけても自動では消しません。

## 送信前の遮断

管理者権限で起動すると、外部への接続を送信前に止めます（使わないときは `--no-gate`）。
遮断の仕組みと切断は、検査用の接続で動作を確認済みです（`--gate-check`）。

1. 通信を確認済みのアプリ、信頼リストのアプリ、PC内とLANへの接続は、そのまま通します。
2. それ以外のアプリが外部へ接続しようとすると、Windowsの段階（WFP）で止めて、まもるんが判定します。
3. 危険度が低ければ許可を追加します。中なら止めたまま確認し、高ければプログラムも一時停止して確認します。

TCPだけでなくUDP（QUICを含む）とIPv6の接続も対象です。止めている間、データは送られません。

遮断をやめるには、右クリックの「15分だけ休ませる」か終了を選びます。
まもるんが異常終了した場合は、Windowsが遮断を自動で取り除きます（通信は止まったままになりません）。
監視の失敗が続いたときも、自動で遮断を解除します。

制限:

- **初めてのアプリの最初の接続は失敗します。** ドライバなしのWFPでは接続を保留できず、いったん拒否して判定するためです。
  多くのアプリは自動で再接続しますが、一度エラーを表示するものがあります。
- PowerShell など悪用されやすい標準ツールは、確認済みでも起動のたびに自動では通しません。
- 対象はログオン中のユーザーのプログラムです。Windowsのサービスと、ストアアプリなどのアプリコンテナは止めません。
- 許可はプログラムの場所ごとです。確認済みアプリのファイルが同じ場所で置き換えられると、遮断では止まりません（監視は続きます）。
- 外部からの接続は対象外です。
- 信頼リストから外しても、次に起動するまで許可は残ります。
- 遮断イベントの収集（Windows全体の設定）を一時的にオンにし、解除時に元へ戻します。
  異常終了したときは、次回の正常な解除で戻します。

## できないこと（重要）

- **管理者権限なしでは、通信を送信前に遮断しません。** 0.5秒ごとの監視で検知してから止めるため、
  検知までに少量のデータが送られる可能性があります。ごく短時間で終わる通信は見逃すことがあります。
- **管理者権限なしでは、UDP（QUICを含む）は監視していません。**
- **確立済みのIPv6接続は切断できません**（プログラムの一時停止は可能です）。
- 通信の**中身は見ません**。判断材料はプログラムの素性と接続先・接続の仕方です。
- 管理者権限で動くマルウェアや、まもるんより高い権限のプログラムは止められず、まもるん自体を終了させられる可能性があります。
  本体が予期せず止まると、見張り役のプロセスが起動し直して知らせます（5分間に3回まで。それ以上は警告だけ）。逆に見張り役が止まると本体が起動し直します。
  ただし両方を同時に止められると検知できません。タスクマネージャーで本体を終了したときも起動し直します。止めるときはメニューの「終了」を使います。
- 判定は経験則の点数付けなので、誤検知も見逃しもあります。
- 外部からの接続は、接続元ごとに通知します。1つのプログラムにつき通知する接続元は20か所までです。

## 既知の弱点（未修正）

- **Windowsの起動時に起動する設定:** 管理者権限で起動する登録なので、EXE をダウンロードやデスクトップなど誰でも書き換えられる場所に置いたまま使うと、
  管理者権限のないマルウェアが EXE を置き換えたときに、次のログオンで権限確認なしに管理者権限で実行されます。この設定を使うなら、EXE を `C:\Program Files` の下など、管理者しか書き込めない場所に置いてください。
- **信頼リストと設定:** `%LOCALAPPDATA%\GuardianMascot` は同じユーザーの通常のプログラムからも書き込める場合があります。マルウェアが自分を信頼リストに書き足すと、判定を逃れられる可能性があります。

## マスコットの画像を差し替える

絵はEXEの中に入っています。差し替えるときは、EXEの隣に `assets\mascot\luce\`（ルーチェ）と `assets\mascot\ansel\`（アンセル）を作り、透過PNGを置いて起動し直します。
ファイル名と画像の条件は、開発フォルダの `assets\mascot\README.txt` を参照してください。

## 保存されるもの

`%LOCALAPPDATA%\GuardianMascot` に保存します（プログラムを入れ替えても残ります）。

- `events.jsonl`: 検知と判断の記録（プログラムのパス、接続先、起動時の引数の先頭300文字を含みます）
- `trust.json`: 信頼済みアプリ
- `seen_apps.json`: 通信を確認済みのアプリ
- `suspended.json`: 停止中のプログラム
- `settings.json`: 表示位置、大きさ、選んだキャラクター

## 開発者向け

```
python tests.py                                      # 単体テスト
python main.py --self-check out.json --shots-dir s   # 実機の自己検査（止めるのは自分で起動した検査用プロセスのみ）
python main.py --scan-once out.json                  # 今の通信を1回判定（何も止めない）
python main.py --gate-check out.json                 # 遮断の実機検査（要管理者。検査用ポートだけを止める）
python main.py --trap-check out.json                 # 罠の実機検査（要管理者。作業フォルダの偽物だけを使い、監査の設定は元に戻す）
powershell -ExecutionPolicy Bypass -File build.ps1   # テスト→自己検査→EXE→EXE自己検査→ZIP
```

| `guardian/signinfo.py` | デジタル署名の詳細（埋め込みとカタログ、証明書チェーン、タイムスタンプ） |
| `guardian/pemeta.py` | 実行ファイルの構造の解析（OSに触れない） |
| `guardian/proginfo.py` | プログラムの調査（バージョン情報、入手元、プロセス、読み込みDLL） |
| `guardian/report.py` | 調査結果と判断材料（OSに触れない） |
| `guardian/reportview.py` | 調査結果の表示用の整形 |
| `guardian/launchwatch.py` | 起動の見張りの点数付け（OSに触れない） |
| `guardian/eventlog.py` | Windowsイベントログの読み取り |

| `guardian/traps.py` | 罠と認証ファイルの見張り、読み取りの検知（要管理者） |
| `guardian/winstatus.py` | Defender などの状態の読み取り |

| `guardian/risk.py` | 危険度の点数付け（OSに触れない） |

| `guardian/ui.py` | マスコット、確認画面、見守り状況画面 |

Windows 11 の一部ビルド（26300で確認）では、TCP接続表の状態値が待ち受けで0、通信中で2になることがあるため、
`winapi.state_name` は相手アドレスの有無も見て判断しています。

## 今後の予定

候補と根拠は `docs/対策調査メモ.md` を参照してください。

- 持ち出しの検知: アプリごとの未知のドメインの検知、定期通信の判定の見直し
- 感染前: スタートアップフォルダへの登録の監視
- 感染後: 見つけた自動起動登録の無効化
- マスコットと Sysmon の保護（停止の検知）

既知のマルウェアの検出（YARA、機械学習、ハッシュ照会）とランサムウェア対策は、Defender の役割なので作りません。
