まもるん 画像の置き場所
========================

キャラクターごとのフォルダにPNGを置きます。
  luce\   聖女ルーチェ
  ansel\  神父アンセル

置き換えたら、マスコットを右クリック →「画像を読み直す」で反映されます。
（再ビルドは不要です。配布版では GuardianMascot.exe の隣の assets\mascot です）

■ ファイル名と場面
  idle.png     ふだん。画面内に立って見守っている（必須）
  watch.png    確認待ち。「これ大丈夫？」と気にしている
  alert.png    危険を止めた。「待って！」と制止している
  sleep.png    監視を一時停止中。立ったまま居眠り
  observe.png  観察モード。じっと観察している
  down.png     監視機能に異常。困っている、倒れそう

  idle.png だけでも動きます。他の状態は idle.png で代用し、右上のランプ色で区別します。

■ 動かしたいとき（任意）
  idle_1.png, idle_2.png, idle_3.png … のように連番にすると0.5秒ごとに切り替わります。

■ 画像の条件
  ・背景は透過（透過PNG）。白背景のままだと白い四角が出ます
  ・全身を入れ、足元を画像の一番下にそろえる（足元の下に余白を残さない）
  ・左右の余白は少なめに。全状態で同じキャンバスサイズ・同じ立ち位置
  ・目安 高さ900px以上の縦長。表示時は高さ160/220/300pxに縮小されます
  ・縮小しても読めるよう、輪郭がはっきりした絵柄がおすすめです
